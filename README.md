# 超级台球大师辅助线加长工具（Root 版）

本仓库的 `root` 分支专门维护需要 Root 的版本，包含独立 Android APK、Windows 桌面工具、源码及测试。

下载 [PoolGuide-1.4.0.apk](PoolGuide-1.4.0.apk)，可在手机上直接调整、应用和恢复，无需电脑。使用说明见 [Android APK](android/README.md)。下面为原桌面版说明。

适配本次分析的阿里渠道版 `com.krmtqds.aligames`。Windows 面板使用 Python 标准库，手机通过 ADB 连接并需要 Root。

## 使用

1. 双击 `启动.cmd`。
2. 点“连接 / 读取状态”，确认手机已连接。
3. 选固定长度（初始 220）或加长倍数（初始 6）；需要撞库预测时，开启“启动时开启反弹预测”。点“应用并重启游戏”，请先结束当前对局。
4. 进入练习球桌并转动球杆。游戏右下角出现“辅助线 220”或“反弹预测 · 最多3次”等标识，说明绘制补丁已加载。

“同时显示碰撞后的分裂线”只在绘制期间临时打开对应视觉开关；取消勾选则遵循游戏原来的开关。

“启动时开启反弹预测”决定游戏启动后的初始状态，默认关闭，旧版设置也默认关闭。游戏右下角提供“反弹预测：开／关”按钮，切换后立即修改已加载补丁的状态并重绘，无需重启；“− / 次数 / ＋”可设置 1–6 次（初始 3 次）。次数保存在游戏本地，下次进入会沿用；重启后的开关初始状态仍以工具中应用的设置为准。青色显示母球，黄色显示首碰目标球，首碰后的两球路径需启用分裂线或游戏原有辅助开关。

物理预测读取当前拉杆力度与高低杆、侧旋，未拉杆时以当前球杆的 100% 最大力度预览，使用游戏自带 `Table.calculateShot` 和独立 `TableTest` 逐步试算，包含台面摩擦、速度/旋转衰减、球间及库边碰撞、袋口处理。未拉杆时显示“未拉杆：100% 满力预览”，拉杆后改为“当前力度”并实时更新预测。母球整条路径及首碰目标球分别受所选次数限制，遇后续球或入袋时停止显示。低杆拉回、高杆跟进不再按零速白球直接停止处理。

固定长度/倍数只用于关闭反弹预测后的直线模式。物理试算仅改变克隆球，不修改真实球状态；复用预测缓存并限制试算时间，达到上限时提示“轨迹已截断”。缺少试算接口时明确显示“方向近似”。场景退出或恢复时释放绘图层、试算缓存和控制面板定时器。

点“恢复并重启游戏”即可恢复原始页面。关闭面板会保留已应用的设置。

### 游戏内动态入袋开关

1.4.0 源码新增两个批量开关，并将原首碰必进一起接入游戏内面板。首次更新仍需结束当前对局后在工具里应用一次；之后展开游戏右下角“入袋开关”，三项功能可直接切换，无需再次重启游戏。工具里的三个开关用于设置启动状态，默认均关闭，旧配置也默认关闭。

- **首碰目标必进**：每杆自己的母球第一次实际碰到目标球后，该球按最近袋口记录入袋。
- **斯诺克：碰红全红入袋**：斯诺克模式中，自己的母球碰到红球后，剩余在台面的红球全部记录入袋。保留母球和彩球，不把红球之间的互撞当作触发。
- **中八：碰球非黑八全入袋**：标准中八模式中，自己的母球碰到目标球（包括黑八）后，在台面的 1–15 号目标球除黑八外全部记录入袋，含双方球组。保留母球和黑八。

模式专用开关在对应模式中优先于首碰必进，三项同时开启也不会通过首碰功能强制收走彩球或黑八。开关开启从下一杆生效；关闭后阻止尚未发生的触发，已入袋的球不会还原。游戏内切换只改变当前运行会话，重新启动后使用工具里保存的启动状态。

对手击球、回放、虚拟预测不触发，推球模式不启用。球按最近袋口直接收进球槽，原有首碰、球组、犯规和黑八规则继续处理，不保证一次触发就是合法得分或获胜。恢复按钮移除全部补丁。

本功能改变客户端入袋记录；联机服务器是否接受、是否回滚尚未验证。此处源码与自动化测试已完成，最终整包构建、安装和应用由负责反弹功能的聊天统一执行。

## 实现与范围

游戏会在启动时更新 `files/swgn8ball/js/main.min.js`，直接改主脚本会被覆盖。本工具在同目录的 `index.html` 中加入一个等待加载的脚本，等 `VisualGuide` 出现后挂接：

- `VisualGuide.calculateGuideLength`：普通辅助线。
- `VisualGuide.calculateGuideLength2`：特殊球杆皮肤辅助线。
- `VisualGuideJiaoCheng.calculateGuideLength`：教程辅助线。

直线模式仅在绘制辅助线时改变返回长度，其他调用沿用原函数。原有首碰预测、犯规标记和球运动逻辑由游戏继续处理。零速度不放大，防止零向量变成非法坐标。反弹模式优先使用独立 `TableTest` 和游戏的击球/摩擦/碰撞函数逐步试算，旧接口环境才退回几何方向预测，在独立 Egret Shape 中绘制母球和目标球路径；观战时沿用游戏原绘制，接口异常时回退到原绘制。

固定长度为逻辑坐标单位，且不会缩短原本更长的线。倍数模式保留原线长比例，结果上限为 1500。直线模式仅延长首碰后的方向线，长线可以穿过球或台边；反弹模式会截断障碍。物理模式按拉杆实际力度、当前旋转和台面减速试算，未拉杆时按满力预览；直线模式仍只延长方向线。试算受采样步长、时间预算及游戏/服务器状态影响，不保证所有实际停点或入袋结果。尚未对真机击球误差做量化对比。

报告中的 `50 × 精准度 + speed × (10 + 10 × 距离因子) − 10` 实际对应教程类。真机普通对局为 `42.5 × speed × 精准度`，特殊皮肤为 `42.5 × 精准度`，因此三个函数分别处理。

## 备份与恢复

- 改动前在手机入口页面旁生成带 SHA-256 的原始备份，并在工具目录 `.backups/<设备>/` 保存相同内容。
- 写入前、写入后分别校验 SHA-256；异常时尝试恢复本次操作之前的完整页面。
- 写入现有文件，保留原 UID、文件权限和 SELinux 标签。
- 重复应用会更新原有补丁，不会叠加。若文件被其他程序改动而校验不符，停止修改。
- 主脚本的日常热更新不影响此加载方式；入口页面被游戏更新替换后，需要重新应用。

## 环境与命令行

需要 Python 3.10+（含 tkinter）、ADB，以及已给 ADB Shell 授予 su 权限的手机。没有 Root 的设备不支持这一版工具。以下命令均在仓库根目录的 PowerShell 中运行。

读取状态：

```bash
python .\guide_extender.py status
```

应用 220 逻辑单位的线长：

```bash
python .\guide_extender.py apply --length 220
```

按原线长放大 6 倍：

```bash
python .\guide_extender.py apply --mode multiply --factor 6
```

开启库边反弹预测（省略此参数即关闭）：

```bash
python .\guide_extender.py apply --bank-prediction
```

开启首碰目标球直接入袋（省略此参数即关闭，可与反弹预测同时使用）：

```bash
python .\guide_extender.py apply --first-hit-pocket
```

恢复原状：

```bash
python .\guide_extender.py restore
```

多台手机时在命令末尾添加 `--serial <adb devices 显示的序列号>`。
