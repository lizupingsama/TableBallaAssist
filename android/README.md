# 台球辅助线 Android APK

成品：[项目根目录的 PoolGuide-1.1.0.apk](../PoolGuide-1.1.0.apk)，应用名“台球辅助线”，包名 `io.lizuping.poolguide`。本目录为 `root` 分支的独立 Android 应用源码。本版沿用 1.0.0 的签名，可覆盖升级。

## 手机上使用

1. 打开“台球辅助线”，点“检查 Root / 读取设置”。首次出现超级用户授权时选择允许。
2. 选择固定长度或倍数，默认长度为 220。需要反弹路径时，打开“库边反弹预测（最多 3 次）”，并保留“同时显示碰撞后的分裂线”以显示首碰后的两球路径。点“应用设置并打开游戏”。开关默认关闭；更改后均需重新应用。
3. 需要还原时，回到工具点“恢复原始辅助线”。

安装后独立运行，不依赖电脑、ADB、Python 或 Frida。当前适配阿里渠道版 `com.krmtqds.aligames`，需要 Root。真机使用 Magisk Delta，工具通过全局挂载命名空间读取游戏资源；未 Root 的手机无法使用这一版。

应用和恢复会重启游戏，请先结束当前对局。关闭工具会保留已应用的设置；卸载工具前，可先执行恢复。

## 备份与兼容

沿用桌面工具的补丁格式，可以读取、修改和还原桌面版已应用的设置。

- 游戏目录保留原始 `index.html.poolguide-original-<SHA256>`。
- 工具自己的私有目录同时保存原文件备份。
- 写入前后校验哈希；失败时尝试恢复操作前的完整文件。
- 保留原入口文件的所有者、权限和 SELinux 标签。
- APK 没有网络权限，不要求无障碍、悬浮窗或存储权限。

反弹开关关闭时延长直线；开启时青色显示母球，黄色显示首碰目标球，每条路径最多 3 次撞库，遇后续球、袋口捕获区域或袋口尖角停止。此时固定长度和倍数不参与反弹绘制。旧版补丁缺少新开关字段时按关闭处理。

使用游戏的库边碰撞响应，在独立虚拟球上计算，不改变实际球运动。方向预览不模拟完整击球力度、台面减速和玩家选定的旋转；不保证实际停点或入袋结果。游戏右下角出现“辅助线 220”或“反弹预测 · 最多3次”等标识说明绘制补丁已加载。

## 构建

需要 Android SDK Build Tools 34.0.0、Android 33 平台和 JDK 11，直接编译 Java、DEX、资源并签名，不依赖 Gradle。优先读取 `ANDROID_HOME`、`JAVA_HOME`，未配置时使用脚本内的 Unity Android 工具链路径。以下命令在仓库根目录的 PowerShell 中运行，产物写入仓库根目录。

```bash
python .\android\build.py
```

可通过 `--sdk`、`--jdk` 指定其他工具链目录。签名密钥保存在 `android/.signing/`，供后续 APK 覆盖升级使用；请保留此目录，不要公开其中的文件。仓库已忽略签名密钥和构建缓存。
