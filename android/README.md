# 台球辅助线 Android APK

成品：[项目根目录的 PoolGuide-1.4.0.apk](../PoolGuide-1.4.0.apk)，应用名“台球辅助线”，包名 `io.lizuping.poolguide`。本目录为 `root` 分支的独立 Android 应用源码。本版沿用原签名，可覆盖升级。

## 手机上使用

1. 打开“台球辅助线”，点“检查 Root / 读取设置”。首次出现超级用户授权时选择允许。
2. 选择固定长度或倍数，默认长度为 220。需要反弹路径时，打开“启动时开启反弹预测”，并保留“同时显示碰撞后的分裂线”以显示首碰后的两球路径。点“应用设置并打开游戏”。这个开关决定启动默认状态，更改后需重新应用一次。之后可在游戏内实时切换反弹并调整 1–6 次，立即重绘，不需要重启；次数会记住。
3. 需要首碰直接入袋时，开启“首次碰撞目标球必进洞”，再点“应用设置并打开游戏”。开关默认关闭，每杆仅处理自己的母球首次碰到的目标球，按最近袋口直接收球；母球和后续碰球保持原有过程。对手、回放和推球模式不触发。
4. 需要还原时，回到工具点“恢复游戏原始设置”，移除辅助线与首碰入袋补丁。

安装后独立运行，不依赖电脑、ADB、Python 或 Frida。当前适配阿里渠道版 `com.krmtqds.aligames`，需要 Root。真机使用 Magisk Delta，工具通过全局挂载命名空间读取游戏资源；未 Root 的手机无法使用这一版。

应用和恢复会重启游戏，请先结束当前对局。关闭工具会保留已应用的设置；卸载工具前，可先执行恢复。

首碰入袋仍保留原有球组、犯规和黑八规则。客户端已记录进球不代表服务器一定接受；服务器认可与真机入袋效果尚未验证。1.2.0 已覆盖安装在 K50，安装后保留当前对局，尚未打开或应用新开关。

## 1.4.0 动态入袋开关

源码已新增“斯诺克碰红全红入袋”和“中八碰球非黑八全入袋”，并把原有首碰必进接入游戏内“入袋开关”折叠面板。首次更新应用后，对局中可直接切换三项功能，不需要返回工具或再次重启。Android 工具中的三项开关配置启动状态，均默认关闭。

开启从下一杆生效，关闭阻止后续触发，已入袋球不还原。斯诺克开关仅收剩余红球，中八开关仅收除母球与黑八之外的普通目标球；模式专用开关优先，避免同时开启首碰必进时误收彩球或黑八。仅作用于自己的母球碰球，不作用于对手、回放、虚拟预测或推球。原有犯规与得分规则继续生效，服务器认可未验证。

当前三项功能的源码、JS 行为测试和跨语言配置检查已稳定。为避免同一工作区相互覆盖，最终构建、安装、应用与整包真机检查由负责反弹功能的聊天统一执行；本聊天没有安装或应用本次批量功能。

## 备份与兼容

沿用桌面工具的补丁格式，可以读取、修改和还原桌面版已应用的设置。

- 游戏目录保留原始 `index.html.poolguide-original-<SHA256>`。
- 工具自己的私有目录同时保存原文件备份。
- 写入前后校验哈希；失败时尝试恢复操作前的完整文件。
- 保留原入口文件的所有者、权限和 SELinux 标签。
- APK 没有网络权限，不要求无障碍、悬浮窗或存储权限。

游戏内“反弹预测：开／关”按钮实时切换，旁边“− / 次数 / ＋”调整每条路径最多 1–6 次撞库。关闭时保留直线延长；开启时青色显示母球、黄色显示首碰目标球，固定长度与倍数不参与物理试算。旧版补丁缺少开关字段时仍按关闭处理。

物理模式使用拉杆的实际力度与当前旋转，未拉杆时按当前球杆的 100% 最大力度预览，通过游戏的 `Table.calculateShot`、独立 `TableTest` 及摩擦/碰撞函数逐步推进，包含速度变化和首碰后白球的跟进/拉回。未拉杆时标明“未拉杆：100% 满力预览”，拉杆后改为实际“当前力度”并实时更新。只改变预测克隆，不修改真实球状态；遇后续碰球或入袋时结束显示。达到试算预算时提示轨迹截断，缺少接口时提示方向近似。实际停点和入袋精度尚需真机量化对比。

## 构建

需要 Android SDK Build Tools 34.0.0、Android 33 平台和 JDK 11，直接编译 Java、DEX、资源并签名，不依赖 Gradle。优先读取 `ANDROID_HOME`、`JAVA_HOME`，未配置时使用脚本内的 Unity Android 工具链路径。以下命令在仓库根目录的 PowerShell 中运行，产物写入仓库根目录。

```bash
python .\android\build.py
```

可通过 `--sdk`、`--jdk` 指定其他工具链目录。签名密钥保存在 `android/.signing/`，供后续 APK 覆盖升级使用；请保留此目录，不要公开其中的文件。仓库已忽略签名密钥和构建缓存。
